# Del Valle Sushi

Carta digital con panel CRUD para categorías y productos.

## Cómo usarla

```bash
npm install
npm run dev
```

- Carta pública: [http://localhost:3000](http://localhost:3000)
- Administración: [http://localhost:3000/admin](http://localhost:3000/admin)

Los cambios se guardan en `data/menu.json`.
